Army Universe

Sitio web para un fandom independiente de BTS en Perú.

  • HTML
  • Tailwind CSS
  • JavaScript
Problema
El fandom necesitaba un espacio para conectar con más fans antes del concierto de 2026, organizar proyectos y dar un primer paso hacia su oficialización.
Decisión
Partí de la identidad visual del grupo y escribí con el lenguaje de la fanbase. Armé un sitio de varias páginas (inicio, blog, eventos y recursos) con secciones para que las visitas participen.
Resultado
Sitio de múltiples páginas, publicado, con navegación clara y elementos de participación para la comunidad: cuenta regresiva al concierto, aviso de entradas y acceso a Discord.
